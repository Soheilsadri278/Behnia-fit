# بهنیا فیت — وب‌سایت مربی شخصی

یک وب‌سایت تک‌صفحه‌ای (Landing Page) فارسی و راست‌به‌چپ برای مربی بدنسازی:
**تمرین شخصی حضوری در فرانکفورت + کوچینگ آنلاین**.

سایت بدون هیچ فریم‌ورک و بدون وابستگی به CDN ساخته شده؛ فقط HTML، CSS و کمی JavaScript.
همهٔ فونت‌ها و تصاویر محلی‌اند، پس سایت آفلاین هم کار می‌کند و سریع بار می‌شود.

## ۲. قبل از انتشار، این‌ها را عوض کنید

### الف) شمارهٔ واتساپ و ایمیل (مهم‌ترین مورد)
در `assets/js/main.js` بالای فایل:

```js
var CONFIG = {
  whatsapp: "490000000000",   // کد کشور + شماره، بدون + و بدون صفر اول
  email: "hallo@behnia-fit.de",
  instagram: "behnia.fit"
};
```

و در `index.html` این موارد را هم با `Ctrl+F` پیدا و جایگزین کنید:
`490000000000` (لینک‌های wa.me) · `hallo@behnia-fit.de` · `@behnia.fit` · `https://instagram.com/`

### ب) عکس‌ها
دو تصویر فعلی فقط جای‌نگهدارند (تصاویر استودیو و ابزار، بدون شخص). جای آن‌ها را با عکس واقعی مربی عوض کنید:

| فایل | نسبت | کجا استفاده می‌شود |
|---|---|---|
| `assets/img/hero-studio.jpg` | عمودی (پیشنهاد ۴:۴.۷) | تصویر بزرگ بالای صفحه |
| `assets/img/detail-equipment.jpg` | مربع | بخش «دربارهٔ من» |

اگر نام فایل را عوض کردید، مسیر `src` را در `index.html` هم به‌روز کنید.
برای عکس‌های قبل/بعد: کلاس `frame` در `index.html` را با `<img>` جایگزین کنید.

### ج) متن‌ها
اعتبارنامه‌های مربی (کارشناسی ارشد فیزیولوژی کاربردی، مربی رسمی فدراسیون،
قهرمان فیتنس، ۵ سال سابقه) در این جاها استفاده شده و همه از یک منبع می‌آیند:

- متای `title` / `description` / Open Graph
- دادهٔ ساختاریافته `<script type="application/ld+json">` (بخش `founder`)
- کیکر بالای تیتر هیرو + نشان دایره‌ای «۵ سال» + کارت نام روی عکس
- نوار اعتبارنامهٔ زیر نوار متحرک (`.authority`)
- پاراگراف‌های بخش «دربارهٔ من» + امضا + چهار تخصص
- سؤال متداول «مدرک و سابقهٔ مربی چیست؟»
- متن فوتر

اگر سال سابقه یا عنوانی تغییر کرد، همهٔ این جاها را با هم به‌روز کنید. جای
`[کروشه]`ها هم منتظر اطلاعات واقعی است: `[نام شاگرد]` · `[نام باشگاه یا استودیو]` …
قیمت‌ها (۸۰ / ۱۹۰ / ۹۰ / ۷۰ یورو و پلن‌ها) هم فقط عدد نمونه‌اند.

> اگر مدرک «مربی رسمی فدراسیون» شامل شمارهٔ گواهی یا نهاد صادرکننده است، افزودن
> آن (مثلاً در بخش تخصص‌ها یا Impressum) اعتماد را بیشتر می‌کند — ولی فقط اگر
> واقعاً قابل ارائه باشد.

### د) گوگل و سئو
در `index.html` این‌ها را با اطلاعات واقعی پر کنید:
- `https://example.com/` در `canonical` و `og:url`
- بلوک `application/ld+json` (نام، آدرس، ساعات کاری، اینستاگرام)
- `og:image` و `twitter:card`

### ه) صفحات حقوقی
در `impressum.html` و `datenschutz.html` همهٔ `[کروشه‌ها]` را پر کنید (نام کامل،
نشانی، تلفن، USt-IdNr.، میزبان سایت) و متن را پیش از انتشار با یک مشاور حقوقی
بازبینی کنید. اگر تحلیل‌گر یا پیکسل تبلیغاتی اضافه کردید، باید در Datenschutz
هم ذکر شود و بنر کوکی لازم می‌شود.

## ۳. اجرای محلی (پیش‌نمایش)

نیازی به build و نصب پکیج نیست؛ فقط پایتون ۳ کافی است:

```bash
python3 server.py            # http://localhost:8000
python3 server.py 3000       # روی پورت دیگر
PORT=8080 python3 server.py  # یا با متغیر محیطی
```

`server.py` یک سرور کوچک توسعه است (بدون هیچ وابستگی خارجی) و چند مزیت بر
`python3 -m http.server` دارد:

- لیست‌شدن پوشه‌ها خاموش است (ساختار فایل‌ها لو نمی‌رود).
- با HTTP/1.1 و keep-alive کار می‌کند، پس بارگذاری صفحه سریع‌تر است.
- برای CSS/JS/فونت/تصویر هدر کش یک‌روزه می‌دهد و HTML را همیشه تازه نگه می‌دارد،
  بنابراین تغییر متن‌ها بلافاصله دیده می‌شود.
- آدرس‌های بدون پسوند (`/impressum`) را مثل هاست واقعی به `impressum.html` نگاشت می‌کند.

> این فایل فقط برای توسعه است و لازم نیست روی هاست نهایی آپلود شود. باز کردن
> مستقیم با دوبار کلیک (`file://`) هم کار می‌کند، ولی از طریق سرور، بارگذاری
> فونت‌ها و تست فرم به رفتار واقعی سایت نزدیک‌تر است.

### چرا CSS و JS کش نمی‌شوند؟
یک‌بار هدر `max-age=86400` برای CSS باعث شد مرورگر نسخهٔ قدیمی را کنار HTML
تازه اجرا کند و صفحه بدون استایل دیده شود (لوگوی غول‌آسا، لینک‌های آبی، دکمهٔ
با رنگ قدیمی). الان:

- `server.py` برای `.css` و `.js` هدر `no-store, must-revalidate` می‌فرستد.
- ارجاع‌ها با `?v=7` نسخه‌بندی شده‌اند؛ با هر تغییر ظاهری عدد را بالا ببرید.
- **استایل حیاتی inline** در `<head>` هر سه صفحه هست: اگر فایل اصلی دیر برسد،
  کش کهنه باشد یا بارگذاری نشود، چیدمان، رنگ برند و اندازهٔ لوگو نمی‌شکند.
- یک **watchdog** کوچک بعد از بارگذاری بررسی می‌کند که استایل واقعاً اعمال شده
  باشد؛ اگر نه، یک‌بار با پارامتر تازه دوباره بارگذاری می‌کند.

> روی هاست واقعی (Netlify/Vercel/هاست ایرانی) پسوند نسخه در `?v=` را بعد از هر
> تغییر CSS بالا ببرید، یا از هش خودکار فایل استفاده کنید.

## ۴. انتشار روی اینترنت (سه گزینه)

| گزینه | هزینه | نکته |
|---|---|---|
| **Netlify Drop** | رایگان | پوشه را در app.netlify.com/drop رها کنید؛ دامنهٔ رایگان + HTTPS |
| **GitHub Pages** | رایگان | Settings → Pages → شاخهٔ `main` را انتخاب کنید |

در آلمان/اروپا **HTTPS اجباری عملی** است (هم برای اعتماد کاربر، هم برای DSGVO).
همهٔ این سه گزینه HTTPS رایگان دارند.

## ۵. ساختار فایل‌ها

```
index.html            صفحهٔ اصلی
impressum.html        اطلاعات ارائه‌دهنده (§ 5 DDG)
datenschutz.html      اطلاعیهٔ حریم خصوصی (DSGVO)
server.py             سرور محلی پیش‌نمایش (فقط برای توسعه)
assets/
  css/style.css       تمام استایل‌ها، با فهرست بخش‌ها در بالای فایل
  js/main.js          منو، آکاردئون، انیمیشن، فرم واتساپ — تنظیمات در CONFIG
  img/                تصاویر سایت + دارایی‌های لوگو
  fonts/              وزیرمتن و استعداد (woff2، مجوز OFL)
tools/
  make-logo-assets.sh ساخت نسخه‌های لوگو از فایل اصلی
```

## ۸. لوگو و هویت بصری

رنگ اصلی برند **سرمهٔ `#14234B`** است که مستقیماً از لوگو گرفته شده؛ کل پالت سایت
(`--brand`, `--brand-deep`, `--brand-soft`) با همین رنگ هم‌راستا شده است.

| فایل | کاربرد |
|---|---|
| `assets/img/logo-source.png` | فایل اصلی لوگو (مرجع) — دست نزنید |
| `logo-mark.png` | مونوگرام سرمه‌ای، شفاف — هدر سایت |
| `logo-mark-light.png` | مونوگرام کرم، شفاف — روی پس‌زمینهٔ تیره |
| `logo-full.png` | لاک‌آپ کامل سرمه‌ای (مونوگرام + وردمارک + تگ‌لاین) |
| `logo-full-light.png` | لاک‌آپ کرم — فوتر تیره |
| `favicon.png` / `apple-touch-icon.png` / `icon-512.png` | فاوآیکون و آیکون اپ |
| `og-image.png` | تصویر پیش‌نمایش در شبکه‌های اجتماعی (۱۲۰۰×۶۳۰) |

نسخه‌های شفاف با اسکریپت `tools/make-logo-assets.sh` ساخته می‌شوند (نیاز به
ImageMagick). اگر لوگو تغییر کرد، فایل اصلی را جایگزین کنید و همان اسکریپت را
اجرا کنید تا همهٔ نسخه‌ها بازسازی شوند:

```bash
./tools/make-logo-assets.sh
```

## ۶. نکته‌های طراحی که عمداً رعایت شده

- **موبایل‌فرست**: بیش از ۷۰٪ بازدید مربیان از موبایل است؛ دکمه‌ها بزرگ و نوار ثابت پایین.
- **یک CTA اصلی** («مشاورهٔ رایگان») که در هدر، هیرو، وسط صفحه و پایان صفحه تکرار می‌شود.
- **قیمت شفاف**: پنهان‌کردن قیمت باعث می‌شود مخاطبِ علاقه‌مند خودش را حذف کند.
- **بدون عکس استوکِ آدم‌ها و بدون نظر جعلی**: اعتماد با محتوای واقعی ساخته می‌شود.
- **راست‌به‌چپ درست**: بدون `letter-spacing` روی متن فارسی، اعداد فارسی برای شماره‌گذاری،
  لاتین‌نویسی‌ها با `dir="ltr"` جدا شده‌اند.
- **دسترس‌پذیری**: کنتراست کافی، `aria-expanded` برای منو و آکاردئون، `focus-visible`،
  احترام به `prefers-reduced-motion`، و لینک پرش به محتوا.
- **بدون وابستگی خارجی**: فونت و تصویر محلی؛ نه رد شدن IP به گوگل، نه مشکل GDPR فونت.
